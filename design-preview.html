05 · SHAPE & MOTION

圆角 · 边框 · 阴影 · 动效

圆角只有三档；阴影只给浮层；动效只有 120ms / 200ms 两档时长 + 一条缓动曲线，且只动合成与绘制属性，不动布局。

圆角 4 / 6 / 8

radius-sm / md / lg
4 控件
6 卡片
8 弹框
标签、开关、进度条不套圆角阶梯，用 999px 或 2px 独立规定

边框只两色

primary 1px 常规
strong 1px 强调
禁止 2px 以上的实线边框；选中态用主色边框 + 主色浅底，不加粗
--shadow-modal: 0 12px 32px rgba(0,0,0,.12); --shadow-card: none; /* 卡片靠边框分层 */

120ms 微交互

hover / focus / 颜色变化 → --dur-fast

200ms 位移

展开、侧栏、抽屉 → --dur-base + --ease

降级

已处理
系统开启"减少动态效果"时，全局动画压到 0.01ms：
@media (prefers-reduced-motion: reduce)

两档时长 + 一条缓动

--dur-fast / --dur-base
120ms颜色 · 边框 · hover
200ms位移 · 展开 · 侧栏折叠
缓动cubic-bezier(.2,.8,.2,1)
裸时长（0.3s / 150ms）与 --transition-* 别名禁用；别名段里的 slow 300ms 全站 0 引用

可动属性白名单

5 + 1 例外
合成transform · opacity
绘制bg-color · color · border
例外width（仅侧栏 200↔60）
height / margin / padding / top / left 一律不做过渡

禁止

4 类
transition all带布局属性，逐帧重排
表格行过渡长表 hover 每行重算
刷新淡入淡出轮询页面周期性闪动
动画改高度触发 CLS
